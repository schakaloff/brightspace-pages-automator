# Quiz Repair in MTB Writer

Nick reviews quizzes migrated from Moodle to Brightspace. The tool compares local exports, identifies missing or changed content, supports explicit question-version choices and manual edits, previews the working copy, and exports a separate candidate ZIP.

## Platform

A local web workspace launched from the existing Windows desktop app, following Structured Transfer. The app stays open and hosts the workspace on this computer. Course exports and saved reviews stay local. No AI service is required for this workflow.

## Confirmed constraints

Use the existing comparison and repair work. Preserve original exports and course settings. Do not silently select a supposedly newer copy, delete blank answers, fabricate missing text, or treat agreement between outdated files as approval. Report missing pictures when the export excludes course files. Brightspace import/appearance/grading verification remains a separate check.

## Audience and workflow

The reviewer needs plain language, clear side-by-side questions, a list of issues, a choice of stored versions, saved reviews and an explicit export action. Nick approved reusing Structured Transfer's local-web pattern and visual vocabulary. Existing transfer tools remain outside this change.
