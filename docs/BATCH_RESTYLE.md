# Restyle selected pages

In **Build & style → Restyle pages**, choose a theme and page design, then paste
a Brightspace page or section URL.

- A page URL restyles that one page.
- A section URL opens a checklist before changing anything. Check any combination
  of pages, including pages that are not next to each other.
- Search filters the checklist without losing selections. The count shows selected
  items hidden by your search. **Select visible** checks matching items;
  **Clear selection** unchecks all items.
- Click **Restyle N selected item(s)** to begin. Cancel or close the checklist to
  leave the course untouched.

The batch processes up to five pages concurrently. Each page keeps the existing
content-preservation and save-verification checks. The log identifies saved and
failed pages, and the progress summary counts saved, failed and skipped items.
A failed page does not stop the remaining selection or trigger an automatic retry.
If saving could not be verified, inspect that page in Brightspace before rerunning it.

**Stop after active pages** lets pages already underway finish and skips the queue.
Keep the app open until those pages finish. The browser remains open after the batch
so you can inspect the course; close it when finished.

**Move unit content into an Overview page** is optional and off by default. When
enabled for a unit URL, the checklist includes the description as a separate item.
It is moved and restyled only if that item is checked.

The Build & style hub groups Create pages and Collect a unit under **Build content**,
with Restyle pages and Remove topics under **Update existing content**. On narrow
windows the top cards stack and the tools remain reachable by scrolling.
