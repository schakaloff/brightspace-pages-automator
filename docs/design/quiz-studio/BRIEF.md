# Quiz Repair workspace

Mode: Operate. Extend the existing Transfer Studio system: locally hosted Hanken Grotesk, warm off-white ground, white work surfaces, teal primary actions, restrained borders, familiar controls. The user explicitly requested the existing Structured Transfer approach and approved the proposed workflow.

Composition: file selection, then a quiz/question list beside a working area. Selected source and working question previews sit side by side on wide screens and stack at narrower widths. Versions are compared before the user applies one. HTML editing is disclosed beneath previews. Blocked export names the remaining question/image problems. Edits save to a local review; export creates a separate package.

No cloud integration, command-line launch, new UI framework, custom rich-text editor or automatic choice of a question version. Matching pairs are displayed and preserved; users can choose another existing matching version, but cannot add/remove matching rows in this version.
